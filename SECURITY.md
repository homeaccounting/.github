# Security Policy

This is the organization-wide default. Repositories that ship their own
`SECURITY.md` — currently [backend](https://github.com/homeaccounting/backend)
and [web](https://github.com/homeaccounting/web) — take precedence over it.

HomeAccounting handles financial data and bank credentials, so security is core
to the product, not an afterthought.

## Reporting a vulnerability

**Please do not open a public issue, discussion, or chat message for security
problems.**

Report privately via either:

- **GitHub Private Vulnerability Reporting** — the **“Report a vulnerability”**
  button under the affected repository’s **Security** tab (preferred).
- **Email** — `security@homeaccounting.com`.

Please include the affected component, steps to reproduce, the impact, and any
suggested remediation.

## What to expect

- **Acknowledgement** within **3 business days**.
- An initial assessment and severity rating within **7 business days**.
- Progress updates through remediation, and a disclosure timeline coordinated
  with you.
- We practise **coordinated disclosure**: please give us reasonable time to fix
  and release before public disclosure (target **90 days**, sooner for
  actively-exploited issues).

Full scope, out-of-scope items, and our security posture are documented in
[backend/SECURITY.md](https://github.com/homeaccounting/backend/blob/master/SECURITY.md).
