# .github

Organization-wide defaults for [HomeAccounting](https://github.com/homeaccounting).

- `profile/README.md` — the landing page shown at
  [github.com/homeaccounting](https://github.com/homeaccounting)
- `SECURITY.md`, `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md` — [default community
  health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file),
  used by any repository in the organization that does not ship its own. A
  repository's own file always wins; these only fill gaps.

This repository is also the **source repository for organization Discussions**,
which means discussion visibility and moderation permissions follow it.

Everything here is public. Nothing internal belongs in this repository.
